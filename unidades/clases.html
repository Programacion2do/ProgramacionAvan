Una clase es una plantilla o molde que describe las características y comportamientos de un tipo de objeto. En Java se define con la palabra clave class. A partir de una clase se pueden crear múltiples objetos, cada uno con su propio estado.

Ejemplo: la clase Perro describe qué es un perro; cada perro individual (Fido, Rex) es un objeto de esa clase.

Los atributos (o campos) representan el estado de un objeto: datos que almacena. Los métodos representan su comportamiento: acciones que puede realizar.

Se declaran dentro de la clase. Los atributos suelen ser private y los métodos public. Un método void no retorna valor; si retorna algo, se indica el tipo (int, String, etc.).

El constructor es un método especial que se ejecuta automáticamente al crear un objeto con new. Tiene el mismo nombre que la clase y no tiene tipo de retorno. Sirve para inicializar los atributos.

Si no definís un constructor, Java crea uno vacío por defecto. Podés tener varios constructores con distintos parámetros (sobrecarga).

El encapsulamiento es el principio de ocultar los datos internos de una clase y exponer solo lo necesario. Se logra declarando atributos como private y accediendo a ellos mediante métodos get y set (getters y setters).

Esto protege la integridad del objeto: nadie puede modificar un atributo directamente sin pasar por las validaciones del setter.
