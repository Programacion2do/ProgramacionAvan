ArrayList y Colecciones

Completada

ArrayList es una lista de tamaño dinámico del paquete java.util. A diferencia de los arrays comunes, puede crecer o achicarse. Sus elementos se acceden por índice (desde 0) con get(i).

Métodos clave: add(), remove(), size(), get(), contains(), clear(). Se recorre fácilmente con for-each.

HashMap almacena pares clave → valor. La clave es única; el valor puede repetirse. Es útil cuando necesitás buscar un dato por un identificador (ej: nombre → nota).

Los Generics permiten indicar el tipo de datos que contendrá una colección en tiempo de compilación: ArrayList<String>, HashMap<String, Integer>. Esto evita errores de tipo en tiempo de ejecución.

Sin generics, las colecciones guardan Object y es necesario hacer casting manual. Con generics el compilador detecta los errores antes de ejecutar.

La clase Collections (con s) ofrece métodos estáticos utilitarios para trabajar con colecciones: Collections.sort(lista) ordena de menor a mayor, Collections.reverse() invierte el orden, Collections.max() y min() obtienen el valor extremo.

Para ordenar objetos propios, la clase debe implementar Comparable o se puede pasar un Comparator.
