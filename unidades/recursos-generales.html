Recursos Generales

🛠 Entorno de desarrollo

☕
Java JDK — Adoptium Versión recomendada: JDK 21 LTS. Gratis y open-source. Instalación obligatoria.
🔵
Visual Studio Code Editor liviano. Instalar la extensión "Extension Pack for Java" para soporte completo.
🟠
IntelliJ IDEA Community IDE completo para Java, versión gratuita. Recomendado para proyectos más grandes.
🐬
MySQL Community Motor de base de datos. Instalar también MySQL Workbench para gestión visual.
⚡
OneCompiler Java Compilador online. Sin instalación. Podés guardar y compartir tus programas.

📐 Diagramas UML

🔷
Lucidchart Diagramas de clase, flujo y ER online y colaborativos. Se usa en varias unidades.
🟦
Draw.io (diagrams.net) Online, gratis, sin instalación. Diagramas de clase, flujo, ER y más.
🌱
PlantUML Generá diagramas UML desde texto plano. Ideal para documentar junto con el código.
📐
Dia Diagram Editor Aplicación de escritorio para diagramas UML. Liviana y sin conexión.

📘
Java SE 21 API Docs Documentación oficial de todas las clases y métodos de Java.
🌐
W3Schools Java Referencia rápida con ejemplos interactivos para cada tema.
🟢
Programiz Java Tutoriales paso a paso con editor online integrado. Muy didáctico.
📗
Head First Java (O'Reilly) El libro más visual y amigable para aprender Java con POO. Muy recomendado.
