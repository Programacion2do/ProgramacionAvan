Conexión a Base de Datos

Completada

JDBC (Java Database Connectivity) es la API estándar de Java para conectarse a bases de datos relacionales. La conexión se establece con DriverManager.getConnection(url, user, password), donde la URL tiene el formato jdbc:mysql://host:puerto/baseDeDatos.

Es fundamental cerrar la conexión al terminar para liberar recursos. Se recomienda usar try-with-resources para garantizarlo automáticamente.

Statement permite ejecutar consultas SQL estáticas (sin parámetros variables). Se crea con con.createStatement().

Para consultas que devuelven filas se usa executeQuery(sql) que retorna un ResultSet. Para INSERT, UPDATE o DELETE se usa executeUpdate(sql). No es seguro contra inyección SQL: nunca uses Statement con datos que ingresa el usuario.

PreparedStatement es la alternativa segura al Statement. La consulta se precompila con ? como marcadores y los valores se asignan después con setString(), setInt(), etc.

Ventajas: previene inyecciones SQL, mejora el rendimiento en consultas repetidas y hace el código más legible. Es la forma recomendada para cualquier consulta con parámetros.

El patrón DAO (Data Access Object) separa la lógica de acceso a datos del resto de la aplicación. Se crea una clase (ej: PersonaDAO) que encapsula todas las operaciones CRUD de una tabla: insertar(), buscarPorId(), listarTodos(), actualizar(), eliminar().

El resto del programa solo llama a esos métodos sin saber cómo están implementados, facilitando mantenimiento y cambios de base de datos.
