Unidad 1

Clases y Objetos

Completada

En Java, una clase es una plantilla que define atributos y comportamientos. Un objeto es una instancia de esa clase creada en tiempo de ejecución con new.

Los atributos representan el estado del objeto y los métodos representan sus acciones. El constructor es un método especial que se ejecuta al crear el objeto.

Ejemplo — ejecutá el código:

  1. Creá una clase Persona con atributos nombre, edad y dni. Agregá un constructor y un método saludar() que imprima los datos.
  2. Instanciá 3 objetos Persona distintos y mostrá sus datos.
  3. Desafío: agregá un método esMayorDeEdad() que retorne boolean.

Unidad 2

Herencia y Polimorfismo

Completada

Herencia (extends) permite que una clase hija reutilice el código de una clase padre. Polimorfismo permite que objetos de distintas subclases sean tratados como objetos de la clase padre.

@Override indica que un método redefine el comportamiento del padre. super permite acceder al constructor o métodos del padre.

Ejemplo — ejecutá el código:

  1. Creá una clase abstracta Figura con el método abstracto area().
  2. Implementá Circulo y Rectangulo que extiendan Figura.
  3. Creá un array Figura[] con distintas figuras e imprimí el área de cada una usando polimorfismo.
  4. Desafío: agregá Triangulo sin modificar el código existente.

Unidad 3

Colecciones — ArrayList y HashMap

Completada

Las colecciones son estructuras dinámicas del paquete java.util. ArrayList es una lista de tamaño variable; HashMap guarda pares clave → valor.

Se recorren con for-each o con iteradores. El uso de Generics (<String>) permite indicar el tipo de los elementos en tiempo de compilación.

Ejemplo — ejecutá el código:

  1. Creá un ArrayList<String> con 5 nombres, ordenalo con Collections.sort() e imprimilo.
  2. Usando un HashMap<String, Integer>, almacená el nombre y la nota de 4 estudiantes. Mostrá quién tiene la nota más alta.
  3. Desafío: combiná ambas estructuras: un ArrayList de Persona con nombre y nota, ordenado de mayor a menor nota.

Unidad 4

JDBC — Conexión a Base de Datos

Completada

JDBC (Java Database Connectivity) es la API estándar de Java para conectarse a bases de datos relacionales. El flujo básico es: DriverManager.getConnection() → crear Statement o PreparedStatement → ejecutar consulta → recorrer ResultSet → cerrar conexión.

Usar PreparedStatement evita inyecciones SQL y mejora el rendimiento en consultas repetidas.

Ejemplo — ejecutá el código:

  1. Escribí el código para conectarte a una base de datos MySQL con JDBC. Manejá la excepción SQLException.
  2. Creá un método listarEstudiantes(Connection con) que haga un SELECT e imprima cada fila.
  3. Usando PreparedStatement, creá un método insertarEstudiante(String nombre, int edad).
  4. Desafío: implementá el patrón DAO (Data Access Object) para la tabla estudiantes.
